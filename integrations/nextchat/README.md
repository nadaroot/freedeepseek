# NextChat (ChatGPT-Next-Web) Integration

### Configuration:

1. Open NextChat settings.
2. Under **Model Provider**, select **OpenAI**.
3. Set the following fields:
   - **OpenAI Endpoint**: `http://127.0.0.1:9655/v1`
   - **API Key**: `sk-freedeepseek`
   - **Custom Models**: `-all,+deepseek-chat,+deepseek-reasoner,+deepseek-r1,+deepseek-v3,+deepseek-vl`
4. Choose `deepseek-chat` or `deepseek-reasoner` as your active model.
